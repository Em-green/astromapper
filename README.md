GitHub Pagesなどの静的ホスティングで使えます。アカウント・APIキー・サーバーは不要です。

- タイミング画面で基準日を変えると古い年間結果をクリア。

## すぐに試す

`index.html` をブラウザで開いてください。
React 18.3.1 と ReactDOM を CDN から読み込むため、初回表示にはインターネット接続が必要です。
通信が制限されている環境では読み込みエラーを表示します。
入力した出生データはブラウザ内だけで処理し、保存・送信しません。
外部フォント・アクセス解析は使用していません。

## 概算の出生時間

境界時刻は次の時間帯に含めます。例：08:00は「午前」、14:00は「午後」。
「深夜」は、入力した生年月日の午前0〜4時で、翌日には繰り越しません。

| 選択肢 | 時間帯 | 計算に使う仮時刻 |
| --- | --- | --- |
| 早朝 | 04:00以上、08:00未満 | 06:00 |
| 午前 | 08:00以上、12:00未満 | 10:00 |
| お昼 | 12:00以上、14:00未満 | 13:00 |
| 午後 | 14:00以上、18:00未満 | 16:00 |
| 夕方・夜 | 18:00以上、22:00未満 | 20:00 |
| 夜遅く | 22:00以上、24:00未満 | 23:00 |
| 深夜 | 00:00以上、04:00未満 | 02:00 |
| 不明 | 時間帯もわからない | 12:00 |

時間帯の全体を検証・平均化する機能ではありません。代表時刻1つで仮計算します。
出生時間が違うと土地のラインや順位は大きく変わり得ます。概算結果を正確な診断と扱わないでください。
都市のUTCオフセットは標準時の固定値です。出生当時のサマータイムや歴史的な時差は手動で調整してください。

## 計算の読み方

元ツールの簡易天体計算・土地ライン計算・トランジット計算を引き継いでいます。
今回、外部の天文暦との照合による精度検証は行っていません。
元データに記載されていた一律の精度保証は、この版では採用していません。

総合ランキングは、元ツールの近接指標を使い、太陽・月・金星・木星の関連と、
火星・土星・天王星・冥王星の関連を別々に集計します。
テーマランキングは、関連する惑星とライン（仕事はMC、家庭はICなど）を組み合わせた独自の簡易ルールです。
ラインとの差が9°未満の場合に `重み × (9 − 角度差)` を加算します。
9°未満の関連するラインがない都市も、参考候補として採用します。
条件を満たす都市の順位は従来のスコア順を維持し、足りない分を関連ラインが近い都市から補って3枠を表示します。
参考候補の順番は、テーマに関係するラインのうち最も近いものとの角度差で決めます。
総合ベスト／ワーストでも、該当が足りない場合は同様に関連ラインが近い都市を補います。

星の基準は、カードの説明に表示しているラインとの差を使います。

| 表示 | ラインとの角度差 | 読み方 |
| --- | --- | --- |
| ★★★ | 3°未満 | よく重なる |
| ★★ | 3°以上9°未満 | 少し離れる |
| ★ | 9°以上 | 遠めの参考候補 |

星は近さの目安で、良い／悪い運勢の強さ、成功確率、診断の精度を示すものではありません。
テーマ別ワーストは、テーマに関連する責任・競争・変化などを表すラインを独自に組み合わせたランキングです。
ベスト順位の逆順ではなく、関連ラインの近接スコアを独立に計算します。
具体的な組み合わせと重みはソースの `THEMES` の `lines`（ベスト）、`worstLines`（ワースト）に記載しています。
同じ都市が両方のランキングに入ることもあります。
ワーストは、必ず悪い出来事が起こるという意味ではありません。

順位は登録都市内の比較で、世界中のあらゆる場所を検索しているわけではありません。
角度差は近接度の簡易指標で、実際の距離（km）でも成功確率でもありません。
金運などの名称は占星術の象徴的な解釈であり、収入・投資成果・未来を予測するものではありません。

## 都市の選定と近隣エリア表示

現時点の対象は、元データの95地点（日本14地点を含む）のままです。
知名度や「旅行したい人が多いか」で候補を落とす基準は設けません。
今後の追加では都市の規模、地域の中心地としての役割、地理的な広がりを基準に見直します。
現在のリストは人口順の網羅リストではなく、バリ島など都市以外の登録地点も含みます。
人口データは今回の計算や並べ替えには使っていません。

都市統計を参照するときは、行政市と都市圏で人口の範囲が違う点を区別します。参考：
- 国連 World Urbanization Prospects： https://population.un.org/wup/
- 日本の国勢調査： https://www.stat.go.jp/data/kokusei/2020/kekka/final.html

表示用のエリアは、国・地域が同じで、すべての登録地点どうしの中心座標間が80km以内となるように、登録順で決定します。
距離は球面上の概算距離です。都市AとB、BとCが近くても、AとCが80kmを超えれば3地点をひとまとまりにはしません。
80kmは表示のための編集上の基準で、公式都市圏や天体計算の精度を示す数値ではありません。
現在は「東京・横浜周辺」「大阪・京都周辺」がまとまり、95地点を93の都市・周辺エリアとして表示します。

都市ごとの天体計算、スコア、★はそのまま残します。
総合／テーマ別のベスト・ワーストは、各都市を従来どおりに並べてから、同じエリアを1枠にまとめます。
各枠の代表は、そのランキングで最も上位の都市です。エリア平均のスコアではありません。
上位3枠を表示し、エリアを開くと各都市のスコアに基づく★・説明・詳細へのボタンを確認できます。
個別の都市検索、出生地選択、タイミング画面では都市をまとめず、各地点の座標を使用します。
